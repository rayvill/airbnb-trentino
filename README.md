# 🏡 Análisis de Alojamientos de Airbnb en Trentino

Este proyecto realiza un análisis exploratorio de datos (EDA) de alojamientos en la región de Trentino utilizando Python en Jupyter Notebook. El objetivo es obtener información útil sobre los precios, tipos de alojamiento, puntuaciones de los usuarios, disponibilidad y distribución geográfica.

## 📁 Estructura del proyecto

│
├── data/

│
├── images/
|  
│── analisis_airbnb_trentino.ipynb
│
├── README.md
└── requirements.txt


## 🧪 Librerías utilizadas

- pandas
- numpy
- matplotlib
- seaborn
- jupyter

## 📊 Análisis realizados

- Dias disponibles al año
- Distribución de precios
- Precio promedio por tipo de habitación
- Relación entre puntuación y precio
- Puntuacion por tipo de alojamiento
- Tipos de habitación más comunes

## 💡 Recomendaciones

- Asegúrate de limpiar correctamente los datos (valores nulos, precios extremos, tipos de datos).
- Utiliza gráficos para comunicar los hallazgos más relevantes.
